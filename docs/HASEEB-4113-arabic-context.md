## Legend

- **Key** — the path in `src/copy/ar.json`; array items appear as `name[0]`, `name[1]` …
- **English source** — the same key in `en.json`, with every `{placeholder}` replaced by the value
  the build renders from `src/fixture/sample-company.json`. The copy files never contain a figure.
- **Current Arabic** — exactly what `ar.json` holds today. “— awaiting Kuwaiti copy review —” marks
  the 8 strings round 7 deliberately left in English (founder §3 and §5: no new Arabic was authored
  this round); the English sentence the Arabic page shows today is printed after it. “same as EN — by
  design” marks the 6 strings that are identical because there is nothing to translate.
- **Where it appears** — page, section, element, and where it matters the state and the moment in time.
- **Screenshot** — file name under `docs/screenshots/HASEEB-4113/ar-context/`. Each is a crop of the live
  Arabic page with that string's own element outlined in a 2 px teal box; open the HTML twin to see them
  inline. Desktop crops are 1440 px wide, phone-only rows 390 px. The film was frozen with its own clock
  and captured at 1.2 s (drifting field) and 5.4 s (three-line block).
- **Length limitation** — measured in the browser: available content width at 1440 and 390, the number of
  lines the current text takes, and any hard single-line constraint.

## Before reading the rows

1. **Growth is mostly free, height is not.** Almost every element wraps. The ones that cannot are the three
   status pills, the amount cells, the launcher's teal tag and the two form inputs — called out in the last
   column. Everywhere else a longer Arabic line pushes the block taller rather than clipping.
2. **The film's word list is sampled, and the sample is fixed.** The 34 tokens on a 1440 field are drawn from
   the 19-entry vocabulary by a seeded generator, so the same entries appear on every run. Five of the
   nineteen — سداد · توصيل · إيصال · تحويل بنكي and `Invoice` — are never drawn at 1440.
3. **Two full film frames**, for the moments the crops are cut from:
   `film-field--tokens.png` (the drifting field at 1.2 s) and `film-statements--block.png`
   (the three-line block at 5.4 s).
4. **The Arabic film vocabulary is one entry shorter than the English.** `ar.json` has 19 tokens,
   `en.json` has 20; the English list ends with an Arabic garnish token (`د.ك {row1Amount}`) the Arabic
   list does not mirror. Nothing breaks, but the two lists are not a key-for-key pair.
